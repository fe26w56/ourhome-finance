## 技術スタック（推奨）

### フロントエンド（確定）
- **フレームワーク**: React 19.x + TypeScript
- **ルーティング**: React Router DOM 7.x
- **スタイリング**: Tailwind CSS
- **グラフ**: Recharts
- **ビルドツール**: Vite

### 状態管理（推奨）
- **クライアント状態**: Zustand
- **サーバー状態**: TanStack Query (React Query)

### バックエンド（推奨）
- **BaaS**: Supabase
  - PostgreSQL（データベース）
  - Supabase Auth（認証）
  - Realtime（リアルタイム同期）
  - Storage（ファイルストレージ）

### 理由
- Supabaseは無料枠が充実
- PostgreSQLによる堅牢なリレーショナルDB
- Row Level Security (RLS) による権限管理
- Realtimeによるデータ同期が標準搭載
- Firebase代替として人気上昇中

## セキュリティ設計方針

1. **認証**: Supabase Auth（メール/パスワード、OAuth）
2. **認可**: PostgreSQL Row Level Security (RLS)
3. **通信**: HTTPS（Supabase標準）
4. **データ保護**: 
   - クライアント側でのセンシティブデータ非保持
   - RLSによるデータアクセス制御
