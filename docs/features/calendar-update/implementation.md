# カレンダーUI改善および表示ロジック変更 実装計画書

参照: `design.md`

## 1. 実施手順

### Step 1: カレンダー生成ロジックの修正
*   **ファイル:** `screens/Calendar.tsx`
*   **内容:** `calendarDays` の `useMemo` 内のロジックを変更する。
*   **詳細:** 42回の固定ループを廃止し、配列の最後が土曜日になるまで翌月の日付を追加するロジックに置き換える。

### Step 2: UIスタイルの調整 (Compact化)
*   **ファイル:** `screens/Calendar.tsx`
*   **変更点:**
    *   グリッドの `gap-y-4` -> `gap-y-2`
    *   日付サークルの `h-10 w-10` -> `h-9 w-9`
    *   コンテナのパディング調整（必要に応じて）

### Step 3: 動作確認
*   `npm run dev` でサーバーを起動（起動済みの場合はリロード）。
*   カレンダー画面で以下の月を表示して行数を確認する。
    *   2026年1月: 5行であることを確認（1/31が土曜なので翌月行は不要）
    *   2026年2月: 2/1が日曜なので、2/28(土)まででぴったり4行になるはず。
*   レイアウト崩れがないか目視確認。

## 2. 必要なコマンド
特になし（エディタ操作のみ）

## 3. テスト項目
*   [ ] カレンダーの日付が正しく連続していること。
*   [ ] 月末が土曜日の場合、次の行（翌月のみの行）が表示されないこと。
*   [ ] 月末が金曜日の場合、土曜日（翌月1日）まで埋められていること。
*   [ ] UIが崩れていないこと（日付サークルが正円を保っているか）。
