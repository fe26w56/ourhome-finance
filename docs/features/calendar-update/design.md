# カレンダーUI改善および表示ロジック変更 設計書

参照: `requirements.md`

## 1. アーキテクチャ概要
`screens/Calendar.tsx` 内の表示ロジックとCSSクラスを変更する。外部ライブラリの追加やデータ構造の変更は行わない。

## 2. 詳細設計

### 2.1 カレンダー生成ロジック (`calendarDays` useMemo)

**現状:**
1. 前月の空白埋め
2. 当月の日付埋め
3. 合計が42個（6週間）になるまで翌月の日付で埋める

**変更後:**
1. **前月の空白埋め**: 変更なし（月の初日の曜日に応じて埋める）。
2. **当月の日付埋め**: 変更なし。
3. **翌月の空白埋め**:
    *   固定数（42）までループするのではなく、「最後の要素の曜日が土曜日（index 6）になるまで」翌月の日付を追加する。
    *   アルゴリズム:
        ```typescript
        // currentDaysは前月分+当月分が既に入っている配列
        const lastDayOfWeek = new Date(currentDays[currentDays.length - 1].dateStr).getDay();
        const remainingDays = 6 - lastDayOfWeek;
        
        for (let i = 1; i <= remainingDays; i++) {
           // 翌月の日付を追加
        }
        ```
    *   これにより、5週または6週（稀に4週）で動的に終了する。

### 2.2 UIコンポーネント変更

**対象ファイル:** `screens/Calendar.tsx`

| 箇所 | 現状 | 変更後 | 備考 |

| グリッドコンテナ | `gap-y-4` | `gap-y-2` | 行間を詰める |
| 日付セル (外側) | `gap-0.5` | `gap-0` | 上下要素（日付と金額）の間隔を詰める |

| 金額フォント | `text-[10px]` | `text-[9px]` | 必要に応じて微調整（視認性確認） |

### 2.3 影響範囲
*   `screens/Calendar.tsx`: UIレンダリング部分および `calendarDays` ロジックのみ。
*   他の画面やグローバルステートへの影響なし。
