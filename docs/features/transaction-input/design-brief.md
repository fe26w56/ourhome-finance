# 取引入力画面 デザインブリーフ

デザイナー向け：UIリデザインのための現状整理

---

## 1. このUIで実現したいこと

### コアバリュー
**「買い物直後に、3秒で支出を記録できる」**

日常の支出を**ストレスなく、素早く**記録し、家計管理を習慣化する。
カップルや家族で共有する支出を、**割り勘も含めて正確に**追跡できる。

### ユーザーゴール（優先度順）
1. **素早さ** - 金額とカテゴリを入れてすぐ保存
2. **正確さ** - 誰が払った？誰のため？を明確に
3. **シンプルさ** - 迷わず入力完了できる

---

## 2. 入力項目と優先度

```
必須（常に表示）
├─ 金額 ← 最重要、最初に目に入るべき
├─ 種別（支出/収入）
├─ カテゴリ
└─ 保存ボタン

条件付き（2人以上のグループ時）
├─ 誰が払った（Who Paid）
├─ 誰のため（For Whom）
└─ 割り勘設定

任意
├─ 日付（デフォルト: 今日）
└─ メモ
```

---

## 3. 現状の課題

### 課題1: 入力の導線が曖昧
- 電卓キーパッド → 詳細フォーム → 保存 の流れが視覚的に分断
- どこから始めればいいか迷う

### 課題2: 情報過多
- 初見で全項目が見えてしまい圧倒される
- 「Who Paid」「For Whom」「割り勘」が縦に並び、スクロールが長い

### 課題3: 割り勘が隠れている
- 折りたたみ状態で、存在に気づかないユーザーがいる
- 「設定」ボタンを押さないと詳細が見えない

### 課題4: 金額入力が遅い
- ¥50,000 を入力するのに 5タップ必要
- クイック入力（¥1,000単位など）がない

---

## 4. 理想のユーザーフロー

```
1. 画面を開く → 金額入力にフォーカス
2. 金額を入力 → カテゴリを選ぶ
3. （必要なら）日付・メンバー・メモを調整
4. 保存 → 完了トースト → 前画面へ
```

**理想時間: 5〜10秒**

## 5. 現在のデザインテイスト

### カラー
- プライマリ: 緑系（アクセント、保存ボタン）
- 背景: ライトグレー / ダーク対応
- エラー: 赤系

### コンポーネント
- 角丸カード（rounded-2xl / 16px）
- Material Symbols アイコン
- セグメントコントロール（支出/収入切り替え）
- チップボタン（受益者選択）
- ボトムシートモーダル（カレンダー、カテゴリ選択）

### トーン
- モダン・ミニマル
- 余白を活かしたレイアウト
- ソフトシャドウ

## 6. デザイン検討のポイント

### 維持したい点
- 電卓スタイルの金額入力（直感的）
- 支出/収入のトグル切り替え
- カテゴリのアイコン+カラー表現
- ボトムシートによるモーダル

### 再考したい点
- 情報の段階的開示（Progressive Disclosure）
- 「誰が払った」「誰のため」の表現方法
- 割り勘設定のアクセシビリティ
- 入力完了までのステップ数削減
